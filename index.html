Proyecto destacado · Web app

PDF Photo Viewer

Si tienes 20 PDFs con una foto en cada uno, abrirlos uno a uno es lento. Esta aplicación los carga todos a la vez (archivos sueltos o una carpeta entera) y muestra la primera página de cada PDF como miniatura en una cuadrícula, con un visor a pantalla completa para verlos en detalle.

  • Arquitectura por componentes en React 19: subida, cuadrícula, miniatura y visor modal.
  • Renderizado de PDF en el navegador con react-pdf / pdf.js, sin subir nada a un servidor.
  • ErrorBoundary para que un archivo dañado no rompa la aplicación.
